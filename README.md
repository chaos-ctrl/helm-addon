# Helm add-on for Home Assistant

**A personal project, not ready for other people yet:** this page exists so its owner's Home Assistant can
install and update it. No support, and things change without notice.

Helm is a private, self-hosted life hub. This repository only holds what Home Assistant needs to install
it; the app itself comes as a ready-made image. Install: Settings > Add-ons > Add-on Store > ⋮ >
Repositories > add `https://github.com/chaos-ctrl/helm-addon`, then install **Helm**. Instructions are in
the add-on's Documentation tab.
